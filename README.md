# 권역별 운영 실험 보드

대화역과 킨텍스 권역의 배달 병목을 데이터와 현장 확인으로 검증하고, 조치 전후 효과와 비용을 기록하는 운영 보드입니다.

## 실행

1. `.env.example`을 `.env`로 복사합니다.
2. 경기도 교통정보 API 키와 카카오 REST API 키를 `.env`에 입력합니다.
3. `node server.mjs`를 실행합니다.
4. 브라우저에서 `http://localhost:4173/`을 엽니다.

주문 수, 라이더 수, 조리 시간은 공개 API로 확인할 수 없어 화면에서 가상 운영 데이터로 구분합니다. `.env`와 실제 키는 저장소에 올리지 않습니다.

## 주요 흐름

권역 선택 → 교통 API 확인 → 원인 가설 비교 → 현장 사실과 제약 기록 → 조치 전후 지연시간과 비용 입력 → 사건 저장 및 CSV 내보내기
